  <action>
    Implement D-305 fully (cross-fade, safe reopen, failure mode, targeted invalidation):

    1. **PageBitmapCache.kt** — Cross-fade render pipeline:
       - Add `renderPageWithCrossFade(pageIndex: Int, scaleBucket: Int): Bitmap` (suspend):
         - Check if entry exists for `(pageIndex, scaleBucket)` — this is the "old bitmap".
         - Start render for new bitmap (same as existing `renderPage` but returns `Bitmap`).
         - When new bitmap ready: if old bitmap exists, trigger cross-fade animation in UI layer (see below), then `put(newKey, newBitmap)`, `refs.acquire(newBitmap)`, release old bitmap via `refs.releaseFromCache(oldBitmap)`, `recycleIfUnreferenced(oldBitmap)`.
         - If no old bitmap (first render), just put new bitmap.
       - Modify existing `getOrRender(pageIndex, scaleBucket)` to use cross-fade when `invalidatePage` was called for that page (track invalidated pages in a `Set<Int>`).
       - Cross-fade duration: 200ms (tween), easing: `FastOutSlowInEasing`.
       - **Key**: Old bitmap stays in cache and displayed until new one is ready — no blank flash.

    2. **ThumbnailCache.kt** — Add `invalidate(pageIndex: Int)`:
       - Remove entry for `pageIndex` from LRU.
       - Recycle bitmap if unreferenced.
       - Called from `ViewModel.triggerReRender(pageIndex)`.

    3. **PdfViewerViewModel.kt** — Safe reopen & failure handling:
       - `reopenRenderingDocument(tempFile: File)`:
         - **New doc first**: `val newHandle = DocumentHandle.open(tempFile)` (using existing `PdfDocumentKt`/`SafDocumentOpener` pattern).
         - Verify: `newHandle.pageCount > 0`, can render page 0.
         - **Then close old**: `currentHandle?.close()`, `cleanupScope.launch(NonCancellable) { currentHandle?.close() }`.
         - Swap: `currentHandle = newHandle`, `currentUri = tempFile.toUri()`.
         - Cancel in-flight renders for old document (existing `renderScope.cancel()` pattern).
         - Update `pageCount`, `pageSizes`, `rotationOracle` for new document.
       - `triggerReRender(pageIndex)`:
         - `pageBitmapCache.invalidatePage(pageIndex)` (all buckets).
         - `thumbnailCache.invalidate(pageIndex)`.
         - `textLayoutCache.remove(pageIndex)`.
         - `blockIdsByPage.remove(pageIndex)`.
         - Kick render for visible pages (existing mechanism picks up invalidation).
       - `executeCommand(cmd)` — Wrap in try/catch:
         - On success: normal flow.
         - On failure (JNI exception, saveAsCopy false, reopen fails):
           - Log error.
           - **Keep old document** (do not swap handles).
           - `_messages.value = ViewerMessage.EditFailed(errorMessage)` → snackbar.
           - **Do not push command to stacks** (edit stays as unsaved draft in editor panel).
           - Editor panel remains open with draft text.
       - `onUndo/onRedo` — Same try/catch failure handling.

    4. **SelectionOverlay.kt** — Robust reselection:
       - `reselectEditedLine(pageIndex: Int, baselineRect: PdfRect, newLayout: TextPageLayout)`:
         - Convert `baselineRect.center` to screen coords via current transform.
         - Hit-test at that screen position using new layout's lines.
         - If hit finds a line: update `selectionState` with that line (new `blockId` from `groupBlocks`).
         - If no hit (layout changed drastically): find nearest line by vertical distance to `baselineRect.center.y`.
         - If still none: clear selection, show snackbar "Selection lost after edit".
         - Called from `ViewModel` after re-render completes (observe `pageBitmapCache` render completion or use `LaunchedEffect` on `textLayoutCache` change).

    5. **EditorPanel.kt** — Rotation/IME polish:
       - `TextField` `keyboardOptions`: `imeAction = ImeAction.Done`, `capitalization = KeyboardCapitalization.Sentences`.
       - Ensure `focusRequester` requests focus on panel appear (LaunchedEffect on `state`).
       - On rotation: `EditorPanelState` survives in ViewModel; `TextField` restores draft text and caret position automatically via `value`/`onValueChange`.
       - No hardcoded strings — all from `strings.xml`.
