## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User text input → Font analysis | Untrusted Unicode strings analyzed for font coverage |
| Font assets (TTF) → JNI → PDFium | Bundled font files loaded into native memory via FD |
| Temp edit file → Rendering document | App-written PDF re-read by rendering pipeline |
| Undo/redo stack → ViewModel state | In-memory command history (user actions) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
