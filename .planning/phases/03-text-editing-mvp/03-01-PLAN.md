<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User touch → ViewModel | Untrusted tap coordinates and text input cross into ViewModel state |
| ViewModel → JNI (PdfEditingEngine) | Command objects and text strings cross Kotlin/JNI boundary |
| JNI → libpdfium.so (native) | Raw pointers, UTF-16 strings, file descriptors cross into native memory |
| SAF file descriptor → EditingDocument | External file handle (user-controlled URI) used to open PDF for editing |
| Temp file → Rendering document reopen | App-written temp file read back by rendering pipeline |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | JNI nativeSetText | high | mitigate | Input validation: `objectIndex` bounds-checked against `FPDFPage_CountObjects`; `newText` length limited (max 10k chars); UTF-8 → UTF-16LE conversion bounds-checked |
| T-03-02 | Information Disclosure | Temp edit file | medium | mitigate | Temp file created in app-private cache dir (`context.cacheDir`), `deleteOnExit()`, not world-readable. No sensitive data in edit temp files (only PDF content user already has access to). |
| T-03-03 | Denial of Service | JNI local reference table overflow | medium | mitigate | `PushLocalFrame`/`PopLocalFrame` in JNI loops (e.g., object enumeration in Plan 03-02). Tracer has no loops but future-proof. |
| T-03-04 | Elevation of Privilege | SAF FD → EditingDocument | low | accept | FD is from user-picked document via `ACTION_OPEN_DOCUMENT`; user already has read access. No privilege escalation. |
| T-03-05 | Tampering | EditorPanel text input | low | mitigate | `TextField` single-line, max length enforced in `updateEditorState` (1.2x original). No HTML/JS injection (Compose TextField is safe). |
| T-03-06 | Repudiation | Edit command stack | low | accept | In-memory stack only (Phase 3); not persisted. Phase 5 adds checkpointing. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new package installs in this plan. `pdfiumandroid` already audited (RESEARCH.md Package Legitimacy Audit). Bundled Liberation fonts from official GitHub releases (verified). |

</threat_model>
